The team

customers.riskmandate.ai · who does what, as files · written at v0.1.0 (2026-10-20) · in the shape of the sgit.ai team section and the riskmandate.ai team page · CC BY 4.0

Three roles fill every seat at this stage, held by one person and one agent. Each role is one file with the rules it enforces and the mistake behind each rule, so that a new agent can read this page and one role and begin. The board of work is board.md, the work as files with a status line each, and needs.md, the asks back to the person. Neither lives in a vault yet; if the board outgrows a file, it moves to a vault of its own and this page says where.

The agents that make riskmandate.ai have behaviour policies of their own on its team page; this site's build agent is a Claude Code session of the same kind and will get one as part of the record the-agents in the batch. Other teams review the work and the review is published with the reply; the first review this site expects is the sgit.ai site team's, against its repository rules.
